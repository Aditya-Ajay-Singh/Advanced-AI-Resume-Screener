
# Advanced AI Resume Screening System

## Features
- Attractive Streamlit UI
- Resume PDF Upload
- ATS Score Calculation
- NLP-Based Skill Extraction
- Missing Skills Detection
- Multiple Job Roles
- Career Recommendation Dashboard

## Job Roles Included
- AI/ML Engineer
- Cybersecurity Analyst
- Web Developer
- Data Analyst
- Cloud Engineer

## Technologies Used
- Python
- Streamlit
- NLP
- Machine Learning
- pdfplumber

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
streamlit run app.py
```
